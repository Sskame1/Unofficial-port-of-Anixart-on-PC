# Клиент Anixart для Windows

Небольшое desktop-приложение на Rust для получения данных эпизода Anixart и открытия страницы источника в Windows x64 без Android-эмулятора.

## Текущее состояние

MVP-клиент реализован. Он запрашивает данные эпизода через гостевой API Anixart и открывает поддерживаемые iframe-ссылки Kodik во встроенном WebView2. Указанные по умолчанию ID приведены только как пример; введите ID доступного вам эпизода.

Во время ручного запуска удалось открыть страницу провайдера, но успешное воспроизведение видео **не подтверждено**. Проверенная страница Kodik не начала воспроизведение, а прямой запрос к endpoint медиа отклонён: для него требуется динамическая проверка `IP`, `deadline` и `sign`. Клиент не генерирует подписи и не обходит эти проверки. Пока это прототип запросов к API и открытия страницы, а не рабочий видеоплеер.

Сейчас приложение поддерживает только iframe-эпизоды Kodik. В нём нет каталога, поиска, входа в аккаунт, управления субтитрами и собственного видеодвижка. В проверенном случае гостевой API Anixart вернул данные эпизода без аккаунта; доступность воспроизведения может зависеть от провайдера и его требований.

## Сборка и запуск

Требования: Windows x64, инструментарий Rust и Microsoft Edge WebView2 Runtime. WebView2 Runtime обычно уже установлен в Windows 10/11.

В корне проекта выполните:

```powershell
cargo run --release
```

Чтобы собрать приложение без запуска:

```powershell
cargo build --release
```

Исполняемый файл появится в `target\release\anixart-windows-client.exe`. Введите в окне ID релиза, типа, источника и позицию эпизода, затем нажмите **Open episode**. Начальные значения: `19053`, `2`, `7` и `1`.

## Содержимое проекта

- `src/` — оболочка desktop-приложения и клиент гостевого API на Rust.
- `web/` — HTML-интерфейс во встроенном WebView2.
- `decompile/` — локально извлечённые файлы APK, результат JADX и заметки; каталог исключён из Git.
- `docs/` — локальные исследовательские и проектные документы; каталог исключён из Git.

Оригинальный файл `anixart_v10-5.apk` хранится локально и исключён из Git. Декомпилированные результаты используются для анализа и не являются восстановленным исходным кодом приложения.
