# Anixart для Windows

Desktop-перенос на Rust на основе предоставленного APK Anixart. Первая цель интерфейса — мобильная компоновка приложения в окне Windows x64. Приложение переносится по функциям и пока не заменяет Android-версию целиком.

## Что уже реализовано

- Интерфейс использует мобильную компоновку APK: верхний поиск, нижнюю панель с пятью разделами, вкладки, быстрые действия и сетку постеров.
- Главная, экран деталей, поиск, выбор эпизодов, закладки, лента, профиль, вход/регистрация/восстановление, настройки, уведомления, расписание, фильтры и коллекции имеют отдельные HTML/CSS экраны или переходы. Данные экранов без подключённого API обозначены как недоступные/гостевые состояния, а не выдумываются.
- Полная карта интерфейсов и оставшихся работ сохранена локально в `docs/UI_PORT_STATUS.md` (каталог docs по-прежнему исключён из Git).
- Отдельные HTML-, CSS- и JavaScript-модули собираются build-скриптом во встроенную страницу WebView.
- Пользователь подтвердил, что `cargo run` запускает окно на Windows x64. Доступны разделы Главная, Обзор, Закладки, Лента и Профиль.
- Главная и «Обзор» запрашивают случайный публичный релиз через гостевой API Anixart. Карточка показывает доступные поля и открывает экран деталей.
- Детали запрашивают релиз, варианты озвучки/субтитров, источники и список эпизодов по цепочке из APK. Открытие Kodik iframe работает как передача странице провайдера, воспроизведение видео не подтверждено.
- Кнопка поиска в верхней панели открывает экран гостевого поиска релизов. Запрос реализован по данным APK, но после последнего обновления ещё не проверен целиком в приложении.
- «Обзор» загружает страницы рекомендаций, обсуждаемого и просматриваемого; расписание показывает списки по семи дням; фильтр отправляет годы и сортировку по контракту APK. Интеграции компилируются, но системный прокси этой среды блокирует проверку с живым API. Остальные поля APK-фильтра пока не подключены к элементам управления.
- Форма эпизода по-прежнему запрашивает метаданные через гостевой API и открывает страницу Kodik во встроенном окне. Фактический просмотр эпизода не подтверждён; сам источник может показывать рекламу.
- В APK обнаружено 42 API-интерфейса и сотни экранных layouts; большая часть экранов и функций аккаунта ещё не перенесена.
- Страница Kodik открывалась, но воспроизведение видео не подтверждено. Проверенный прямой endpoint потребовал динамические параметры `IP`, `deadline` и `sign`. Приложение не обходит эту проверку.

Пользователь подтвердил, что ранее `cargo run` запускал приложение и каталог получил реальные данные. Несколько HTML-экранов не проверены в окне из-за ошибки WebView2 `0x8000FFFF`. Сейчас среда не может обращаться к Anixart: настроенный прокси отклоняет подключения на `127.0.0.1:9`; поэтому новые запросы расписания, обзора и фильтра проверены сборкой, но не живым API. Авторизация, списки аккаунта, лента и профиль пока требуют реализации. Прямое воспроизведение видео не подтверждено.

## Сборка и запуск

Требования: Windows x64, инструментарий Rust и Microsoft Edge WebView2 Runtime (обычно уже установлен в Windows 10/11).

```powershell
cargo run --release
```

Сборка без запуска:

```powershell
cargo build --release
```

Исполняемый файл: `target\release\anixart-windows-client.exe`.

## Структура проекта

- `src/app/` — состояние приложения, маршруты и обработка команд.
- `src/api/` — общий HTTP-клиент, конфигурация и ошибки.
- `src/features/player/` — поиск эпизода и передача поддерживаемому источнику.
- `web/styles/`, `web/components/`, `web/screens/`, `web/services/` — раздельные модули интерфейса.
- `decompile/` — локально извлечённый APK и результаты исследования; каталог исключён из Git.
- `docs/` — локальный дизайн, планы переноса и инвентаризация; каталог исключён из Git.

Порядок переноса описан в `docs/superpowers/plans/2026-10-26-anixart-port-roadmap.md`: основа, публичный каталог, авторизация, личная библиотека, социальные функции, настройки и видео/проверка паритета.
