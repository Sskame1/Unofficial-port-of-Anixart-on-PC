# Windows Anixart video client

Небольшой Rust-клиент для просмотра видео Anixart на Windows x64 без Android-эмулятора. Работа над приложением ещё не началась: сейчас исследован APK версии 10.5 и подтверждён гостевой API-путь до ссылки Kodik. Прямое воспроизведение через mpv пока не проверено.

## Roadmap

- [x] Исследовать APK и сохранить результаты в `decompile/APK_RESEARCH.md`.
- [ ] Получать эпизод Anixart через публичный API без входа.
- [ ] Поддержать разрешение ссылок одного источника Kodik.
- [ ] Запускать видео в mpv; добавить паузу, продолжение, перемотку и закрытие.
- [ ] Проверить сборку и воспроизведение на Windows x64, документировать зависимости и лицензии.

## Планируемый запуск

Когда клиент будет реализован, здесь появятся точные команды сборки и запуска, требования к mpv и примечания по поддерживаемым источникам.
